# organize-dispute-materials 6.8.1

一次提取当前记录全部附件并逐文件展开压缩包。图片通过平台原生智能体调用能力逐项交给纠纷材料视觉核验员核验。视觉智能体从同一 Base 记录重新下载指定附件，OCR 只用于定位。音频先生成不可变快照，再通过飞书妙记生成并远端读回逐字稿。纠纷材料整理专员唯一合并事实并生成固定 XML 报告。质量行由程序确定生成。Base 案件名称和日期必须绑定材料哈希与逐字引文。类型和状态必须与报告事实一致。阶段提交、最终提交及失败恢复均先分类当前 Base 和文档状态。最终写后重新读回 Base、完整报告和全部上传人权限。三方一致才返回完成。
