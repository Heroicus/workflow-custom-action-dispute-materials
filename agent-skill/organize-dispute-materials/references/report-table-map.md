# 报告填写映射

复制的 Docx 是唯一模板。按模板标题定位表格，不改标题、表头、行列、审核区或签核区。

| 模板位置 | 填写内容 |
|---|---|
| 一、案件基础信息 | Base 的案件编号；材料中的案件来源、案件类型、案由、受理机构、案号、日期、状态、我方地位、标的额及已载明人员信息。 |
| 2.1 我方当事人 | 我方主体、信用代码、法定代表人、地址、联系人、部门。 |
| 2.2 对方当事人 | 对方主体、类型、信用代码、电话、地址、角色、关联案件；法定代表人只能填法定代表人栏，不得填代理律师/律所。 |
| 2.3 第三人 / 其他关联方 | 仅填写材料明确出现的第三人或关联方。 |
| 三、请求事项 | 每一项诉讼请求或反请求各占一行，金额、依据和证据写入同一行。 |
| 4.1 事实时间线 | 材料中每一项有日期或明确期间的事件各占一行；超出预留行时在同表续行。 |
| 4.2 事实争议点 | 每一项双方分歧各占一行；我方主张、对方主张、证据对比和待补项只写本争议内容。 |
| 5.1–5.4 | 依次填写争议焦点、我方论证、对方抗辩及反驳、材料载明的法律或合同依据。 |
| 6.1 证据总表 | 材料中的每个证据编号各占一行，填写名称、类型、目的、原件情况、页数、日期和三性备注；超出预留行时在同表续行。 |
| 6.2 证据分组 | 按证明目的列出证据分组及证据编号。 |
| 6.3 对方证据及质证意见 | 只写对方实际提交或明确主张的证据及质证意见；没有对方证据时写 `未提供对方证据`。不得写金额、利息、违约金或我方证据。 |
| 6.4 证据瑕疵与补强清单 | 只写材料明确显示的证据缺口、瑕疵和补强动作；没有时写 `未发现明确缺口`。不得写金额或计算结果。 |
| 7.1 请求金额汇总 | 只写本金、违约金、利息、费用和合计的金额、公式、起止日及标准。 |
| 7.2 利息/违约金分段计算明细 | 有分段或明确计算式时逐段填写；没有分段时填写已有的单段计算式。 |
| 八、程序进展记录 | 填写程序节点、管辖与受理、保全/鉴定/评估；没有发生的事项标明未载明。 |
| 九、裁判 / 裁决结果 | 只填写已提供的裁判或执行事实；未提供裁判文书时填写未提供。 |
| 十、费用与成本 | 只填写材料明确的费用或未载明。 |
| 十一、风险提示与建议 | 仅基于当前材料填写风险和后续处理建议；材料外的法律判断标待法务审核。 |
| 十二、待办事项 | 材料明确列出的待办、关联部分、负责人、期限、状态逐项填写。 |
| 十三、材料完整性核查 | 对合同、主体、授权、付款、履行、验收、沟通、程序、证据目录等逐项标注已提供、待补或未载明。 |
| 十四、矛盾信息登记 | 仅登记材料内明确矛盾；无明确矛盾时写 `未发现明确矛盾`。 |
| 十五、AI输出质量自检 | 填写案件编号、主体、请求、时间线、证据、金额、程序、回写八项的读取核验结果。 |

## 交付前读取核验

读取生成后的 Docx。附件存在下列内容时，报告对应位置必须有非占位内容：请求事项、时间线、双方争议、法律或合同依据、证据编号、金额计算、程序节点、待办事项、材料完整性。

- 证据编号数量与 6.1 已填证据行数量一致；
- 时间线数量与 4.1 已填事件行数量一致；
- 对方证据表和证据瑕疵表不得出现金额、利息、违约金或我方证据；
- 7.1 和 7.2 不得为空，只要材料存在金额或计算式；
- 13、14、15 不得保留整表空白或 `人工复核` 占位；
- 任一项不满足，返回 `REPORT_COVERAGE_INCOMPLETE`，不交付链接。
