# 正式报告模板位置映射

复制的飞书 Docx 是唯一正式模板。保留模板标题、章节、表头、审核区和签字区；只把材料明确事实写进对应位置。没有事实的位置保持空白。

| 模板位置 | 允许写入的事实 |
|---|---|
| 一、案件基础信息 | Base 案件编号；材料明确记载的案件来源、案件类型、案由、受理机构、案号、日期、状态、我方地位、标的额和经办人员。 |
| 2.1 我方当事人 | 我方主体、信用代码、法定代表人、地址、联系人、部门。 |
| 2.2 对方当事人 | 对方主体、主体类型、信用代码、电话、地址、角色、关联案件。代理律师不得写入法定代表人栏。 |
| 2.3 第三人 / 其他关联方 | 材料明确出现的第三人或其他关联方。 |
| 三、请求事项 | 材料明确列出的诉讼请求、仲裁请求或反请求；每项单独一行。 |
| 4.1 事实时间线 | 有明确日期或期间的事件；每项单独一行。 |
| 4.2 事实争议点 | 材料明确记载的双方分歧、主张和对应证据。 |
| 5.1–5.4 | 材料明确记载的争议焦点、双方论述及引用的法律、合同条款。 |
| 6.1 证据总表 | 每个附件或材料明确编号的证据；填写名称、类型、证明目的、原件情况、页数和日期。 |
| 6.2 证据分组 | 材料能够确认的证明目的及对应证据编号。 |
| 6.3 对方证据及质证意见 | 对方实际提交的证据和材料中已有的质证意见。 |
| 6.4 证据瑕疵与补强清单 | 仅填写材料自身明确指出的瑕疵或补强事项。 |
| 7.1 请求金额汇总 | 材料明确记载的本金、违约金、利息、费用和合计。 |
| 7.2 利息/违约金分段计算明细 | 材料明确给出的计算式、标准、起止日期和分段结果。 |
| 八、程序进展记录 | 已发生并由材料明确记载的立案、受理、管辖、保全、鉴定、开庭或执行节点。 |
| 九、裁判 / 裁决结果 | 已提供裁判、裁决或执行文书中明确记载的结果。 |
| 十、费用与成本 | 材料明确记载的诉讼费、仲裁费、律师费、保全费、鉴定费等。 |
| 十一、风险提示与建议 | 只写材料原文中已经存在的风险或建议；不得由 AI 自行生成。 |
| 十二、待办事项 | 材料原文中已经明确列出的待办、负责人、期限和状态。 |
| 十三、材料完整性核查 | 只写材料原文已有的完整性说明；不得自行列缺失清单。 |
| 十四、矛盾信息登记 | 只登记不同材料之间能够直接确认的冲突。 |
| 十五、AI输出质量自检 | 保持空白。 |

## 空白规则

- 不写 `未载明`、`未提供`、`无`、`需补充`、`人工复核` 或其他占位文字；
- 不以空格、连字符或 `null` 文本填充模板；
- 模板原有示例值或占位文字应从可填写单元格中清除；
- 补充材料只增加新事实，不重复写入报告中已有事实。
