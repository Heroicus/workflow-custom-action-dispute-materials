# 视觉证据契约

## 固定角色

```text
名称：纠纷材料视觉核验员
传输：真实图片附件会话
权限：只读当前消息中的唯一图片，只返回证据 JSON
```

纠纷材料视觉核验员不配置业务技能，不读取 Base，不下载其他文件，不调用其他智能体，不填写事实脚手架，不生成报告，不写入 Base、文档、云盘或权限。纠纷材料整理专员是唯一事实合并者和业务写入者。

## 任务选择

视觉任务只允许来自以下三类材料：

1. 独立图片附件。
2. PDF 扫描页，包括带整页扫描图和文字层的页面。
3. Office 或 PDF 中达到有效尺寸的嵌入图片。

具有足够原生文字层且不是整页扫描图的 PDF 页面直接使用文字层，不再整页提交视觉核验。装饰图标和小尺寸标识不生成视觉任务。

## 输入链路

`vision_tool.py prepare` 读取运行信封、附件下载封印和 `vision-task/v3` 清单。每项任务必须完成以下链路：

1. 校验本地视觉单元的文件名、字节数、像素尺寸、转换记录和 SHA-256。
2. 将视觉单元绑定到下载封印中的唯一 Base 附件 token、文件名、字节数和 SHA-256。
3. 将不可变图片快照上传到纠纷材料视觉核验员的附件会话。
4. 创建只包含一张真实图片和一项任务的会话。
5. 创建全部会话后统一轮询结果。
6. 保存附件上传、会话创建和结果读回的原始响应与 SHA-256。

不得合并任务，不得用提示词或 OCR 文字替代图片，不得让视觉智能体重新读取 Base。网络或命令明确失败时直接返回精确错误，不做无依据重复调用。

## 输出

每次只能返回符合 `vision-result-schema.json` 的一个 `vision-evidence/v3` JSON 对象。

- `verbatim_text` 只包含图片实际可见文字。
- 不总结，不解释，不重排，不归类，不补全，不规范化。
- 原图未出现的标题、标签、单位、说明和占位词不得添加。
- 空白区域直接跳过。
- 无法逐字确认的字符不得猜测，只写入 `uncertain_regions`。
- 姓名、机构、案号、日期、金额、利率、账号、验证码、印章代码或裁判结果不确定时，`critical` 必须为 `true`。
- `source_sha256`、`image_sha256` 和 `task_id` 必须原样返回。
- `producer.agent_name` 固定为 `纠纷材料视觉核验员`。
- 不得返回 Markdown、解释或契约外文字。

## 成功门

`transcribe` 严格解析唯一 JSON，校验任务身份、图片哈希、附件会话回执和远端响应哈希。格式错误、关键内容不清或状态不完整时不得进入报告生成。

`reconcile` 再次校验视觉单元、Base 来源绑定、提示词哈希、远端回执、结果哈希、回执集合哈希和任务哈希。缺少任务结果、来源不一致、回执不完整、契约外字段或关键内容未决时，本轮不得返回完成。
